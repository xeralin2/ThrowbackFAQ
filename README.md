Your guide to downloading, setting up and playing older Rainbow Six Siege seasons.

<br>

**Building**

For a local run you need [pnpm](https://pnpm.io/).

```sh
git clone https://github.com/xeralin2/ThrowbackFAQ.git
cd ThrowbackFAQ
pnpm install
pnpm dev
```
